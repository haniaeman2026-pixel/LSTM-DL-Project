#  Twitter Sentiment Analysis Using LSTM

##  Overview

This project is a **Deep Learning-based Twitter Sentiment Analysis System** built using **LSTM (Long Short-Term Memory)** networks.  
The model predicts whether a tweet expresses a **Positive** or **Negative** sentiment.

---

##  Features

 Text preprocessing and cleaning  
 Tokenization & sequence padding  
 LSTM-based sentiment classification  
 Real-time tweet prediction  
 Achieved **92%+ Accuracy**
